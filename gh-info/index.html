oriz-resume — the source & story behind resume.oriz.in

A free resume builder that runs entirely in your browser: ATS-clean templates, print→PDF, JSON import/export, and an optional AI tailor. This is the info page — the live tool is over there.

What it is

Resume builder — ATS-clean templates, print→PDF, JSON import/export, optional AI tailor. Fill a form, watch it typeset live on a true A4 preview, then save straight to PDF from your browser's print dialog.

Key features

  • 4 ATS-clean templates — Ledger, Compact, Modern, Classic — plus 6 accent colors.
  • Live typesetting — every keystroke re-typesets the printable page.
  • Print → PDF — scoped print stylesheet for pixel-clean output.
  • Autosave — debounced save to your browser's localStorage.
  • Import / export JSON — portable, human-readable, move between machines.
  • Job-match check — paste a job description for an offline keyword-gap score.
  • Optional AI — rewrite or tailor a bullet; the core builder works even if AI is down.

How it's built

  • Client-only Astro (static) + React 19 islands + Tailwind v4.
  • g4f AI via @chirag127/oz-ai — multi-provider failover, no API key, lazy-loaded.
  • PWA-installable — add to home screen, works offline.
  • 100% in-browser — no upload, no signup, no server. Your resume never leaves the device.
